# 💈 Barbearia

Sistema de agendamento para barbearia em Laravel 11 e VueJs

## 🚀 Como instalar

```bash

git clone https://github.com/viniciusbarboosa/api-barbearia.git
cd api-barbearia


composer install
npm install


cp .env.example .env
php artisan key:generate


php artisan migrate


php artisan serve
npm run dev
